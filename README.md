# 🤖 ربات هوش مصنوعی تلگرام روی Cloudflare

ربات هوش مصنوعی اختصاصی با ساختار تجاری، کاملاً روی Cloudflare (پلن رایگان) و **بدون هیچ API هوش مصنوعی خارجی**؛ مدل‌ها روی خود Cloudflare (Workers AI) اجرا می‌شوند.

## قابلیت‌ها
- 🌐 دسترسی به اینترنت: جستجو + خواندن صفحه‌ها (بدون کلید؛ با Brave API اختیاری پایدارتر می‌شود)
- 🖼️ فهم عکس: متن داخل عکس را می‌خواند و از کپشن/گفتگو می‌فهمد چه می‌خواهید
- 🎨 ساخت تصویر (FLUX)
- 🎙️ پیام صوتی (Whisper)
- 🧠 حافظه: تاریخچه گفتگو + خلاصه‌سازی خودکار + حافظه بلندمدت (`/memory`, `/forget`) روی D1 رایگان
- 💼 تجاری: پلن‌ها (free/pro/vip) با سهمیه، فعال‌سازی پلن، مسدودسازی، پیام همگانی، پنل مدیریت وب، صفحه فرود برند
- 👥 کار در گروه (با منشن یا ریپلای)

## 🟠 بخش ایتا (ایجنت کانال)
با دستور **/eitaa** در همین ربات باز می‌شود (بازگشت: دکمه‌ی «🔙 بازگشت به هوش مصنوعی» یا /ai):
- ثبت توکن ایتایار، افزودن کانال، ارسال فوری/زمان‌بندی پست (متن و فایل)
- 🤖 **ایجنت هوشمند**: با زبان ساده بگویید چه کاری و چه ساعتی انجام شود؛ از کانال‌های عمومی ایتا محتوا می‌خواند، امضای منبع را برمی‌دارد و امضای شما را می‌گذارد
- 💬 **گفتگوی زنده**: «برای تست یک سلام توی کانالم بفرست» ← همان لحظه می‌فرستد و نتیجه‌ی واقعی را می‌گوید؛ «آخرین پست @کانال را واسم بفرست» ← برای خودتان می‌فرستد
- از همان مدل Workers AI ربات استفاده می‌کند (بدون کلید اضافه)؛ اگر سهمیه تمام شد موتور قانون‌محور کارهای «از کانال بیاور» را ادامه می‌دهد
- دسترسی: مالک همیشه؛ بقیه فقط با پلن pro/vip (`/grant ID pro 30`)
- جدول‌ها با پیشوند `ea_` ساخته می‌شوند و به جدول‌های ربات هوش مصنوعی دست نمی‌زنند؛ کران حالا هر دقیقه اجرا می‌شود
- کد منبع بخش ایتا در `eitaa-src/` (TypeScript) و خروجی آماده در `src/eitaa.js` است. بعد از تغییر: `npm i -D esbuild typescript` سپس `npm run build:eitaa`

## نصب (۳ مرحله)
1. این پوشه را در یک مخزن GitHub بگذارید.
2. روی کامپیوتر (Node.js 18+): `node setup.mjs`
3. اسکریپت به‌ترتیب می‌پرسد: توکن Cloudflare (و دسترسی‌های لازم را می‌گوید) ← لینک GitHub ← توکن ربات و شناسه مالک ← در پایان **لینک سایت و یوزرنیم ربات** را می‌دهد.

### دسترسی‌های توکن Cloudflare
`Account › Workers Scripts › Edit` ، `Account › D1 › Edit` ، `Account › Account Settings › Read`

## بعد از نصب (در ربات، با حساب مالک)
- `/diag` تست سلامت همه‌ی قابلیت‌ها
- `/panel` لینک پنل مدیریت (۲۴ ساعت اعتبار)
- `/grant ID pro 30` فعال‌سازی پلن · `/setprompt` شخصیت/قوانین ربات

## محدودیت پلن رایگان
Workers AI روزانه ۱۰٬۰۰۰ نورون رایگان می‌دهد (ریست ۰۰:۰۰ UTC = ۰۳:۳۰ تهران). برای کاربران زیاد پلن Workers Paid لازم می‌شود؛ سهمیه‌ها را از پنل تنظیم کنید.
